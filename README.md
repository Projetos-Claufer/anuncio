# Mensagem no chaveiro

Página de mensagem personalizada aberta por uma tag NFC ou QR Code em um chaveiro.

- `index.html` mostra a mensagem. O conteúdo vem de `conteudo.json`.
- `admin.html` é o painel para editar cartas, recadinhos, fotos, músicas e os textos da página, sem código.
- Este repositório é o modelo e a demonstração do produto, com uma mensagem de aniversário de exemplo.

Use apenas músicas com licença para uso comercial.
